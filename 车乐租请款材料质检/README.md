# 搭子开团微信小程序原型

这是一个原生微信小程序原型，UI 参考点单类小程序的结构：顶部活动区、紧凑卡片、蓝色主操作、底部结算式固定操作栏。

## 已实现

- 首页查看开团列表和人数进度
- 创建开团：标题、人数限制、年龄、性别、身高、体重、自定义限制
- 详情页查看开团内容和已加入成员
- 点击“转发到微信群”拉起微信分享面板
- 点击“立即加入”填写昵称后加入
- 本地 `wx.setStorageSync` 模拟数据存取

## 需要接入后端后才能上线的点

- 真实多人数据同步：当前只是本机本地存储，微信群内其他人不会共享同一份数据。
- 用户身份：不能静默获取微信昵称或群昵称，生产版应使用微信登录获得 `openid`，昵称可由用户授权/填写。
- 群上下文：分享到群可通过分享卡片进入指定团，但自动跳转微信群、静默识别所有群成员不属于普通小程序能力。
